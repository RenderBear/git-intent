# Optional outcome review

Review the exact candidate tree against the task-specific acceptance IDs. For each required ID,
record `satisfied`, `not-satisfied`, or `unresolved`, give a prose rationale, and cite evidence in the
candidate. This review is separate from the mandatory preservation review for existing architecture
and contracts.

Only a complete `satisfied` review can advance to landing. If the prospective tree changes, repeat
the outcome review against the new tree.
