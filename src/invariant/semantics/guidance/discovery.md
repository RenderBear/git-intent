# Progressive discovery

Capture an evidence-backed change in repository understanding whenever implementation exposes an
implicit decision, contradiction, undocumented dependency, missing artifact, or meaningful absence.
Record the observation, exact-tree basis, relevance, and current disposition in prose.

A discovery is evidence, not authority. It may resolve into architecture, a contract, a domain
clarification, code, documentation, tests, follow-up work, another discovery, or no repository
change. Absence claims must state where and how the repository was searched and bind that search to
an exact tree.
